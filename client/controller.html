Repair access on the remote Mac

Connect to the remote Mac's desktop from your local computer. Open System Settings → Privacy & Security → Full Disk Access. Add the helper below and enable it. Authenticate as the owner if asked. Restart the helper if macOS requests it, then retry the blocked operation.

A local approval uses access the helper already has. Initial macOS consent may require interaction on the remote desktop.
